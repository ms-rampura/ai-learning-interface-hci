# User-Controlled AI Learning Interfaces

HCI research project exploring how explanation-format controls affect students' task performance, perceived control, and usability when interacting with an AI learning interface.

## Research questions
1. How do user-controlled explanation formats affect students' task performance?
2. How does explanation customization influence perceived control and usability?
3. Which explanation controls do students find most useful?

## Prototype conditions
- **Condition A:** Conventional AI chat with a fixed-format response.
- **Condition B:** AI learning interface with Summary, Step-by-Step, Worked Example, Simplify, and Clarify controls.

The Figma prototype uses simulated responses. Do not describe it as a live AI system unless a real model is later integrated.

## Getting started
1. Add your approved proposal to `docs/`.
2. Replace the placeholder Figma URL in `prototype/figma/README.md`.
3. Create a literature matrix using `research/literature-review/literature-matrix.csv`.
4. Track tasks using GitHub Issues or a GitHub Project board.
5. Record only real user-study findings; never fabricate participants or results.

## Team workflow
- Create an issue for each task.
- Use branches for substantial changes, e.g. `docs/literature-review` or `study/task-design`.
- Open a pull request and ask another teammate to review it before merging.
- Keep the `main` branch in a working state.

## Ethics and privacy
Collect only the information necessary for the study. Follow instructor and institutional requirements for consent and approval. Do not commit names, contact details, recordings, or other identifiable participant data. Add any sensitive or raw data to `.gitignore` and store it in an approved secure location.
